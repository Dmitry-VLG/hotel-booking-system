# Результаты ручной проверки системы бронирования отелей

Дата оформления отчёта: 7 ноября 2026 года.

## Условия проверки

Приложения запущены локально. Внешние запросы направлялись через API Gateway по адресу http://127.0.0.1:8080. Использовались демонстрационные учётные записи USER и ADMIN. Команды выполнялись в PowerShell.

## Проверки административных функций

| № | Сценарий | Ожидаемый результат | Наблюдаемый результат | Итог |
|---|---|---|---|---|
| 1 | USER alice запрашивает GET /api/users с обновлённым токеном | Доступ запрещён, HTTP 403 | Получен HTTP 403 | Пройдено |
| 2 | ADMIN запрашивает GET /api/users | Доступен список пользователей с ролями | Получены admin — ADMIN, alice — USER, bob — USER | Пройдено |
| 3 | ADMIN запрашивает GET /api/admin/rooms | Доступны действующие номера, включая операционно недоступные | Получены номера 101, 102, 103, 201; у 103 available=false | Пройдено |
| 4 | ADMIN запрашивает статистику после отмены тестовой брони | За проверяемый период занятых ночей нет; исторический счётчик подтверждений сохранён | occupiedNights=0 и occupancyPercent=0 для трёх номеров первого отеля; timesBooked=1 у 101 | Пройдено |
| 5 | Создание отеля через POST /api/hotels | Возвращён созданный объект с идентификатором | Создан отель id=3, name=Demo Hotel, address=Test Street 10 | Пройдено |
| 6 | Чтение созданного отеля через GET /api/hotels/3 | Возвращены сохранённые данные | Получены id=3, Demo Hotel, Test Street 10 | Пройдено |
| 7 | Изменение отеля через PATCH /api/hotels/3 | Идентификатор сохранён, поля обновлены | Получены id=3, Updated Demo Hotel, Test Street 20 | Пройдено |
| 8 | Удаление учебного отеля через DELETE /api/hotels/3 | Успешное удаление, HTTP 204 | Получен HTTP 204 | Пройдено |

### Полученная статистика первого отеля

| roomId | number | timesBooked | occupiedNights | capacityNights | occupancyPercent |
|---:|---|---:|---:|---:|---:|
| 1 | 101 | 1 | 0 | 2 | 0 |
| 2 | 102 | 0 | 0 | 2 | 0 |
| 3 | 103 | 0 | 0 | 2 | 0 |

timesBooked отражает историю подтверждений. Отмена пользователем сохраняет этот счётчик. occupiedNights отражает текущие подтверждённые резервы в запрошенном периоде. Ёмкость в данной реализации вычисляется для существующих активных записей номеров; отдельная история ремонтов не моделируется.
