# Открытие проекта в IntelliJ IDEA

1. Откройте корневой `pom.xml` как Maven-проект.
2. В Project Structure выберите JDK 21 и наследование Project SDK для модулей.
3. В настройках Maven выберите Project JDK для Importing и Runner. Выполните Reload All Maven Projects.
4. Перед запуском из терминала проверьте `java -version` и `mvn -version`.
5. Создайте собственные ключи, если файлов `keys/private.pem` и `keys/public.pem` ещё нет. Не заменяйте существующую пару при работающих приложениях.
6. Выполните `mvn clean verify`, затем настройте окружение и запустите сервисы по [инструкции](manual.md).

Обычная сборка включает пять модулей и корневой POM. Профиль `e2e` добавляет модуль автоматических сквозных проверок. `common` — библиотека, запускать её отдельно не нужно. Maven groupId и пакеты Java не обязаны совпадать.

`tools/GenerateKeys.java` запускается как отдельный исходный файл. Предупреждение IntelliJ о расположении этого файла вне source root ожидаемо.
